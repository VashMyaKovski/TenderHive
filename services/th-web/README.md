# th-web

Дашборд TenderHive на Blazor Server (.NET 10). Работает только через REST API
[`th-gateway`](../th-gateway/README.md): своей базы данных у дашборда нет, роль и объект
доступа проверяет шлюз, поэтому обязательную остановку нельзя обойти через интерфейс.

## Разделы

| Страница | Назначение |
|---|---|
| `/login` | вход по логину и паролю, токен хранится в сессии компонента |
| `/jobs` | список заданий со статусами и фильтрами |
| `/jobs/{id}` | карточка задания: шаги, результат с основаниями остановки, артефакты, согласования |
| `/decisions` | открытые карточки согласования; действия только «согласовать» и «отклонить» |
| `/kb` | версии базы знаний, активация и откат, журнал активации (роль администратора БЗ) |

## Запуск

```sh
cp services/th-web/.env.example services/th-web/.env   # GATEWAY_BASE_URL
dotnet run --project services/th-web                   # http://127.0.0.1:8081
```

В Compose дашборд поднимается вместе со шлюзом:

```sh
docker compose --profile gateway up --build --wait
```

## Настройки

| Переменная | Назначение |
|---|---|
| `GATEWAY_BASE_URL` | адрес API шлюза, по умолчанию `http://127.0.0.1:8080` |

Демонстрационные пользователи и пароль задаёт шлюз (`DEMO_PASSWORD`), дашборд их не хранит.
