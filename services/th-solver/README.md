# TenderHive solver

POST /api/v1/solve принимает задание с закреплённой версией знаний, нормализованные требования, факты, профиль и результаты A2A. Правила указывают поле факта, оператор и ожидаемое значение. Оценка включает покрытия позиций, смету, выводы по требованиям, основания, риски и причины остановки. Результаты модели служат основанием оценки риска.

В `requirements` принимается вывод `th-docintel` со структурированным `source`, единицей измерения, версией шаблонов и признаком `needs_review`. Демонстрационное правило срока действия предложения сравнивает введённый срок с указанным в документе минимумом рабочих дней. Сроки поставки и подачи требуют собственных фактов. Если сведений недостаточно или условие нельзя однозначно сопоставить с правилом, решатель возвращает `NEEDS_REVIEW` для этого требования.

Убыток по смете или невыполненное обязательное требование дают `NO_SOLUTION` и рекомендацию `NOT_PARTICIPATE`. При нулевой или положительной марже ниже порога решатель возвращает `LOW_MARGIN`. Результат оценки риска, помеченный как согласованный, сохраняется в пояснении.

Чтобы проверить покрытие дефицита, передайте исходное наличие и необязательный объект `supply_confirmation` у позиции. Он содержит подтверждённый объём `quantity`, дату поставки `delivery_date` и общую дополнительную стоимость `additional_cost`. Решатель включает поставку в смету и наличие, если её дата укладывается в `supply_deadline`. Остаток дефицита после проверки подтверждения даёт `NO_SOLUTION`. Если у позиции есть точная цена за весь объём, передайте `offer_total_price`.

Шлюз знаний предоставляет контекст и ссылки на источники. Журнал хранит идентификаторы, версию, статус и причины остановки в схеме th_solver. Укажите значения из .env.example, выполните python -m tender_solver migrate, затем запустите python -m tender_solver. Проверка GET /healthz подтверждает доступность схемы.

Для разработки используйте uv sync --locked, uv run --locked ruff check ., uv run --locked ruff format --check ., uv run --locked pyright и uv run --locked pytest.
