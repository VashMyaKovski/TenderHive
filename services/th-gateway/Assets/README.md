# Шрифт для экспорта PDF

`Roboto-Regular.ttf` — гарнитура Roboto (Google), лицензия Apache License 2.0,
версия 2.x. Источник: <https://github.com/googlefonts/roboto-2>.

Шрифт встроен в вывод PDF, чтобы кириллица отображалась одинаково на Windows
и в контейнере, где системные шрифты могут отсутствовать. Регистрация выполняется
в `Services/ArtifactExporter.cs` при первом экспорте.
